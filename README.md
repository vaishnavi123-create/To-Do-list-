# To-Do List Project

## Description
A simple Python-based To-Do List application for managing daily tasks efficiently. This project helps users organize, track, and manage their tasks in an easy and user-friendly way.

## Features
- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Save tasks in a text file
- Simple and easy-to-use interface

## Technologies Used
- Python
- HTML
- File Handling

## Project Files
- main.py - Main application logic
- gui.py - Graphical User Interface
- python app.py - Application entry point
- index.html - Frontend page
- tasks.txt - Stores task data

## How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Run the Python file:
   ```bash
   python main.py
